# Open Fortune - 开放财富

透明化投资平台 - 用真实收益数据见证财富增长

## 核心理念

Open Fortune 通过公开透明的投资组合和真实收益追踪，让投资者看到每一个周期的实际表现，建立信任，形成订阅闭环。

## 功能特性

### 📊 真实收益追踪
- 完整的历史投资周期记录
- 累计收益、平均收益实时展示
- 每个周期的详细收益报告

### 💼 智能投资组合
- 基于前期表现动态调整配置
- 6只精选科技股票
- 目标收益10%/90天

### 📈 个股走势预测
- 历史30天 + 未来90天走势图
- AI驱动的价格预测
- 置信度评估

### 🔄 投资闭环
- 每90天一个周期
- 收益自动滚入下一周期
- 持续优化投资策略
